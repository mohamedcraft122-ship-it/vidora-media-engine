# Vidora Media Engine

ده المحرك الخلفي التجريبي لموقع Vidora.

## طريقة النشر على Render
1. فك ضغط الملف على جهازك.
2. ارفع **محتويات المجلد** إلى مستودع GitHub، وليس ملف ZIP نفسه.
3. في Render اختر New ثم Web Service واربط مستودع GitHub.
4. استخدم إعداد Docker إذا طُلب منك تحديد طريقة التشغيل، ثم ابدأ النشر.
5. بعد النشر افتح رابط الخدمة متبوعاً بـ `/api/health` للتأكد من أن المحرك يعمل.
6. ضع رابط الخدمة الأساسي في واجهة Vidora بدلاً من `PUT_YOUR_RENDER_URL_HERE`.

## ملاحظات مهمة
- ده مشروع بداية تجريبي ولم يتم اختباره مع كل روابط Facebook وInstagram.
- يعمل فقط مع الروابط العامة التي يستطيع yt-dlp الوصول إليها؛ وقد تتغير المنصات أو تمنع الاستخراج.
- لا يستخدم تسجيل دخول أو ملفات cookies ولا يتجاوز الخصوصية أو الحماية.
- لا ترفع كلمات مرورك أو ملفات cookies.
- قبل فتح الخدمة للجمهور، قيّد CORS على نطاق موقعك وأضف حدود استخدام وحماية من إساءة الاستخدام.
- خطة Render المجانية قد توقف الخدمة عند عدم الاستخدام.
